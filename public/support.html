Support

Last updated: May 7, 2026

Need a hand? Most issues are solvable in under a minute by tapping through the right Settings screen. Below are the common ones, plus how to file a bug or feature request.

Common questions

Why is my study progress gone?

Most likely cause is iOS Safari evicting the local storage that backs Kanjido. On iOS native: Settings → Backups → Restore from iCloud. On web: if you exported a JSON backup previously, Settings → Import.

I subscribed but Pro features are still locked.

Open Settings → Subscription → Refresh status. This forces a fresh receipt check with Apple. If that doesn't help, tap "Already paid? Restore purchases" — same Apple ID, same device.

Daily reminders aren't firing.

Two checks: Settings → Notifications inside Kanjido must show the toggle on, AND iOS Settings → Notifications → Kanjido must show "Allow Notifications" on. If iOS denied permission previously, you'll need to enable it from the system Settings app.

My .apkg import won't load.

The newest Anki format (.anki21b, zstd-compressed) isn't supported yet. In Anki: File → Export, enable "Support older Anki versions" and re-export. Alternatively, export your deck as Notes in Plain Text (.txt) and paste it into Kanjido's import box.

Bug reports & feature requests

Open an issue at github.com/cacoleman16/kanji-app/issues. Include:

  • What you were trying to do.
  • What happened instead.
  • Your iOS version and the Kanjido version (Settings → About at the bottom).

For privacy concerns or anything you'd rather not post publicly, email support@kanjido.app.

Account deletion

Kanjido has no accounts, so there's nothing for us to delete on a server. To remove all on-device data: Settings → Delete all my data. Active subscriptions are managed in your Apple ID's subscription settings — cancelling there stops the renewal.

Data export

Settings → Backups → Export saves a JSON file you can keep or migrate to another device. The format is documented in our GitHub repo.
